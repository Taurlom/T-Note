# TimeManager

Небольшое Android-приложение для тайм-менеджмента: категории и списки задач.

## Стек

- **Язык:** Kotlin
- **UI:** Jetpack Compose (Material3)
- **Архитектура:** MVVM + Clean Architecture
- **Хранилище:** Room (локальная база данных)
- **DI:** Hilt
- **Навигация:** Jetpack Navigation Compose
- **Асинхронность:** Kotlin Coroutines + Flow

## Структура проекта

```
app/src/main/java/com/example/timemanager/
├── data/                 # Работа с данными (Room, мапперы, репозитории)
├── di/                   # Модули Hilt
├── domain/               # Бизнес-логика (модели, репозитории, use-case)
├── presentation/         # UI (экраны, ViewModel, компоненты, навигация, тема)
├── MainActivity.kt
└── TimeManagerApplication.kt
```

## Что уже реализовано

- Экран категорий: создание, редактирование, удаление, выбор цвета.
- Экран задач внутри категории: добавление, редактирование, удаление, отметка выполнения.
- Локальное хранение в Room.
- Flat UI на Material3.
