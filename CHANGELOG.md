# Changelog — T-Note

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [семантического версионирования](https://semver.org/lang/ru/):

- **MAJOR** — несовместимые изменения концепции приложения;
- **MINOR** — новые пользовательские возможности;
- **PATCH** — исправления и мелкие доработки.

`versionCode` в `app/build.gradle.kts` = MAJOR·100 + MINOR·10 + PATCH
(например, 1.6.0 → 116). Релиз помечается аннотированным тегом `vX.Y.Z`;
push тега запускает GitHub Actions, который собирает подписанный APK
и прикреплёт его к GitHub Release.

Все выпуски до 1.6.0 восстановлены по истории git и носят обзорный характер:
до внедрения релиз-процесса изменения фиксировались только в сообщениях коммитов.

## [1.9.0] — 2026-09-24

### Добавлено
- «Поделиться списком»: кнопка в шапке экрана задач отправляет список текстом
  (название + пункты с отметками выполнения и описаниями) в любой мессенджер,
  SMS или почту — получателю не нужен T-Note. Первые юнит-тесты формата текста.
- «Поделиться фото» в галерее документов: системный `ACTION_SEND` через
  FileProvider (папка фотографий документов добавлена в `file_paths.xml`),
  в списке получателей — Telegram, MAX и любое приложение, принимающее
  изображения. Отправляется актуальный файл, включая повороты.
- Цвет верхней панели при прокрутке: роль `appBarScrolledContainer` во всех
  темах; панель плавно меняет цвет, когда контент прокручен под неё.
  Подключено на экранах задач, документов, календаря, настроек и документа
  (настройки теперь вообще прокручиваются — раньше контент упирался в низ).
- Внизу настроек — версия приложения (`versionName` и `versionCode`),
  для сверки с релизами.

## [1.8.0] — 2026-09-23

### Добавлено
- Резервные копии в настройках: экспорт всех данных одним zip-файлом
  (база Room, фотографии документов, выбранные тема и шрифт) и восстановление
  из него. Работает офлайн, без сетевых разрешений — файл выбирается через
  системный диалог (SAF). Перед экспортом WAL-журнал базы сливается в файл,
  архив проверяется по манифесту (в т.ч. от zip slip), восстановление требует
  подтверждения и перезапуска приложения.
- Раздел «Резервные копии» в возможностях README.

### Изменено
- Отладочные сборки подписываются релизным ключом: debug- и release-сборки
  для Android теперь «одно приложение» и обновляют друг друга без
  переустановки и потери данных. Флаг `-PkeepDebugSigning` оставляет
  обычный отладочный ключ — он нужен был для переходного билда с экспортом,
  который ставился поверх приложений, подписанных старым debug-ключом.

## [1.7.0] — 2026-09-23

### Добавлено
- Цветовая тема «Осень» (тёплая кофейно-рыжая): пятая в селекторе настроек.
- Единый компонент выпадающего списка `AppDropdown` (поле + меню ширины поля,
  иконки и произвольный рендер пунктов, тёмный/светлый фон, маркер обязательности).
- Маркер обязательных полей: необязательный параметр `required` у `AppTextField`
  и `AppDropdown` рисует звёздочку в лейбле; цвет — новая роль палитры
  `requiredMarker` со значением в каждой теме.
- Общий компонент фото-плитки `PhotoTile` (загрузка Coil, ключ перезагрузки
  после кропа/поворота, скругление из темы) и `RemovablePhotoTile` — с крестиком
  удаления для диалога редактирования документа.

### Изменено
- Во всех диалогах кнопка «Отмена» заменена крестиком в правом верхнем углу
  (`AppDialog`): закрытие по нему, клику вне окна и «Назад» одинаково сбрасывает
  всё незаполненное. В диалогах дня и события кнопка «Удалить» сохранена.
- Четыре локальные реализации выпадающего списка («Копировать в» в задаче,
  тип события, селекторы темы и шрифта в настройках) сведены к `AppDropdown`.
- Галерея фотографий на экране документа: вместо горизонтальной ленты мелких
  квадратов — сетка по два крупных фото в ряд.
- Чекбокс «Удалять прошедшие» выровнен по левому краю полей: material3 1.3.x
  больше не читает устаревший `LocalMinimumInteractiveComponentEnforcement`,
  отключение 48-dp зоны касания переведено на `LocalMinimumInteractiveComponentSize`.
- `AppTextField` принял параметр `onDarkBackground` — настройки больше не рисуют
  `OutlinedTextField` напрямую.

## [1.6.0] — 2026-09-23

### Добавлено
- Релиз-процесс: GitHub Actions собирает подписанный release APK по тегу `vX.Y.Z`
  и публикует GitHub Release с APK и выдержкой из этого changelog (`.github/workflows/release.yml`).
- CI-проверка каждого пуша и PR: компиляция + юнит-тесты (`.github/workflows/ci.yml`).
- Подпись релизов отдельным ключом (keystore + секреты репозитория),
  настройка через `keystore.properties` (вне репозитория).
- Версионирование синхронизировано: `versionName`/`versionCode` теперь
  соответствуют тегу и этому changelog (раньше в Gradle числилась 1.0).

### Изменено
- Структура репозитория: из git исключены артефакты сборки (`app/build/generated`),
  кэш IDE (`.idea`), логи и временные дампы; `.gitignore` переписан.
- Обновлены README и документация проекта.

## [1.5.0] — 2026-09-22

### Добавлено
- Свайп между разделами (первая версия) и свайп месяцев по вертикали в календаре.
- Подсветка «выходного» на днях из соседних месяцев: даты с типом события
  «Выходной» запрашиваются глобально и видны в сетке любого месяца.

### Изменено
- Дни соседних месяцев в сетке календаря неактивны: заметки и события
  добавляются только в дни своего месяца.
- В редакторе повторяющегося события чекбокс «Удалять прошедшие» выровнен
  по левому краю с полями и перенесён под «Повторять дней».

### Удалено
- Поле «Повторять» (раз в день/неделю/месяц) у событий календаря: остался
  только интервал «раз в сколько дней». Миграция БД (v13) пересчитывает
  ранее заданные периоды в дни (день=1, неделя=7, месяц=30) без потери частоты.
