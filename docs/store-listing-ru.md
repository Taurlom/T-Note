# Листинг T-Note для магазинов (RuStore, затем Google Play)

Все тексты — готовые, копировать как есть. Поля и лимиты сверять с подсказками
консоли: площадки иногда меняют ограничения.

## Основное

| Поле | Значение |
|---|---|
| Название (≤30) | `T-Note: списки и календарь` |
| Краткое описание (≤80) | `Офлайн-планировщик: списки, календарь с событиями и документы с фото.` |
| Категория | Продуктивность |
| Возрастной рейтинг | 0+ (в вопросниках везде «нет»: без насилия, рекламы, покупок, личного общения) |
| Ключевые слова | планировщик, списки, задачи, календарь, заметки, документы, офлайн |
| Цена | Бесплатно, без покупок и рекламы |

## Полное описание

Списки — категории с цветами; задачи с описанием, отметкой выполнения,
перетаскиванием и копированием в другой список; отправка списка текстом
в любой мессенджер или файлом .tnote — другой пользователь T-Note
импортирует его одним касанием.

Заметки — длинный текст с markdown-форматированием: заголовки, жирный,
списки, ссылки. К заметке крепятся фотографии (до 10) — сетка в просмотре
и полноэкранная галерея; поворот без потери качества, кадрирование в
родном разрешении. Порядок списка настраивается перетаскиванием, в превью
метки не показываются. Текст или ссылку из любого приложения можно
отправить в T-Note системным «Поделиться» — они превращаются в заметку.

Календарь — заметки на день; события четырёх типов: обычные (иконка и
цвет), дни рождения (повторяются ежегодно), повторяющиеся (интервал
«раз в N дней», длительность, скрытие прошедших) и «Выходной» (подсветка
дня как Сб/Вс, видна и в соседних месяцах). Напоминание-сводка: раз
в день в заданное время приложение само напомнит о событиях дня —
локально, без интернета, расписание переживает перезагрузку; тап
по уведомлению открывает календарь. Навигация: свайп влево/вправо между
разделами, свайп вверх/вниз по календарю — между месяцами.

Документы — карточки с описанием и фотографиями (до 4): галерея с зумом,
поворотом, кадрированием и отправкой фото в мессенджер; съёмка камерой;
порядок списка настраивается перетаскиванием.

Настройки — язык интерфейса (Русский, English, Español — по языку системы
или вручную), 5 цветовых тем (Тёмная, Светлая, Океан, Лес, Осень)
и 10 шрифтов, применяются мгновенно. Разделы приложения можно показывать
или скрывать и расставлять в любом порядке («Настройка разделов») —
нижняя панель и стартовый экран подстраиваются.

Резервные копии — экспорт всех данных (списки, заметки с фотографиями,
календарь, документы с фотографиями, настройки) в один zip-файл
и восстановление из него. Полностью офлайн: файл выбирается через
системный диалог Android. При создании копия сама проверяет целостность
ссылок на фотографии и сообщает, если что-то из них отсутствует.

## Что нового для загрузки 1.17.0

RuStore стоит на 1.14.0 — поле «Что нового» версии 1.17.0 должно охватить
изменения 1.15–1.17:

— напоминание-сводка о событиях дня: локально, без интернета, время
  настраивается, тап открывает календарь;
— текст или ссылку из любого приложения можно отправить в T-Note
  системным «Поделиться» — они превращаются в заметку;
— тактильный отклик: отметка задачи и завершение перетаскивания
  подтверждаются короткой вибрацией;
— набранный текст и открытые диалоги переживают поворот экрана и смену
  темы, языка и масштаба шрифта;
— видимые разделы панели и их порядок включаются в резервную копию;
— восстановление из копии устойчиво к сбоям: версия схемы проверяется
  до подмены данных, при ошибке — откат, опасные архивы отклоняются;
— ссылки в заметках: почта и телефон открываются почтовым приложением
  и звонилкой, небезопасные схемы не открываются;
— системный жест «назад» на Android 14+ показывает превью приложения
  и не закрывает редактор заметки с черновиком;
— пикер времени и переключатели окрашены темой приложения.

## Приватность (для форм «Безопасность данных»)

Данные не собираются и никуда не передаются: приложение полностью офлайн.
Единственное запрашиваемое разрешение — уведомления (Android 13+), и только
при включении напоминаний-сводок. Резервные копии пользователь создаёт сам
и хранит у себя.

## Скриншоты (с телефона, вертикальные; минимум 3, лучше 6)

1. Раздел «Списки» с несколькими карточками;
2. экран списка с пунктами (часть отмечены);
3. календарь с событиями и заметками на месяце;
4. диалог дня календаря (заметка + события);
5. раздел «Документы» или карточка документа с фотографиями;
6. настройки (тема/шрифт/язык).

Снимать обычным скриншотом телефона (1080×2340/2400 подходят). Перед съёмкой
выбрать тёмную тему и наполнить демо-данные, чтобы кадры не были пустыми.
К 1.17.0: кадр настроек устарел — появился раздел «Календарь»; стоит
переснять его и добавить кадр уведомления-сводки.

## Путь в консоли RuStore

1. developers.rustore.ru → вход через Госуслуги → регистрация физического
   лица (данные подтянутся из ЕСИА, нужны email и телефон); модерация
   профиля обычно до суток.
2. «Создать приложение» → указать **package name** (см. решение про
   applicationId ниже — имя задаётся один раз и навсегда) и название.
3. Карточка приложения: тексты из таблицы выше, категория, возрастной
   вопросник (всё «нет» → 0+), загрузить иконку, обложку, скриншоты.
4. Сборка: загрузить APK → дождаться обработки (проверка подписи/версии).
5. «Отправить на модерацию» → 1–3 дня → публикация. Каждый следующий релиз
   проходит модерацию заново.

## Важно до создания приложения в любом магазине

Текущий package `com.example.timemanager`:
— префикс `com.example` зарезервирован — Google Play не примет такое приложение;
— package name в обоих магазинах фиксируется при создании и не меняется.

Поэтому до регистрации меняем `applicationId` на `ru.taurlom.tnote`
(код и namespace не трогаем — меняется одна строка в build.gradle).
Для уже установленных копий это новая установка: перенос данных — через
«Сохранить копию» → «Восстановить из копии».
