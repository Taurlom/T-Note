Политика конфиденциальности T-Note

Действует с 11 ноября 2026 года.

Общие положения

T-Note («приложение») — офлайн-приложение для Android, разработанное независимым разработчиком («разработчик»). Разработчик не собирает, не хранит и не передаёт какие-либо данные пользователей на собственные серверы: у приложения нет серверной части, аналитики, рекламы и телеметрии.

Какие данные обрабатывает приложение

  • Заметки, списки и календарные события — хранятся локально в базе данных на устройстве пользователя.
  • Учётные данные для синхронизации (логин и пароль приложения календарного сервера либо OAuth-токен Google) — хранятся только на устройстве пользователя и используются исключительно для доступа к календарю, подключённому самим пользователем.

Синхронизация с календарными сервисами

Если пользователь подключил синхронизацию, приложение обменивается событиями с выбранным пользователем календарным сервисом:

  • Яндекс Календарь — по протоколу CalDAV (caldav.yandex.ru) с логином и паролем приложения, созданным пользователем в настройках Яндекса;
  • Google Календарь — по Google Calendar API с токеном, полученным через OAuth 2.0 по согласию пользователя.

Приложение использует доступ к Google Календарю (scope https://www.googleapis.com/auth/calendar.events) только для чтения, создания, изменения и удаления событий календаря, подключённого самим пользователем. Доступ к другим данным Google-аккаунта не запрашивается и не используется. Данные не используются для рекламы, не продаются и не передаются третьим лицам, кроме указанных выше календарных сервисов, выбранных самим пользователем.

Проверка обновлений

Раз в сутки приложение анонимно проверяет наличие новой версии: один GET-запрос к публичной странице приложения в каталоге RuStore (rustore.ru). Ни какие-либо данные пользователя, ни идентификаторы устройства при этом не передаются — запрос не содержит ничего, кроме адреса страницы приложения. Если обнаружена более новая версия, приложение показывает уведомление или диалог со ссылкой на RuStore; установку выполняет сам магазин. Без доступа к сети проверка просто не выполняется и ни на что не влияет, кроме содержимого упомянутого уведомления.

Удаление данных

Пользователь может в любой момент отключить синхронизацию в настройках приложения (токен и учётные данные удаляются с устройства), удалить события и заметки внутри приложения или удалить приложение целиком — все локальные данные при этом стираются с устройства.

Права Google-аккаунта

Отозвать доступ приложения к своему Google-аккаунту можно в настройках аккаунта: myaccount.google.com/permissions.
