Политика конфиденциальности T-Note

Действует с 11 ноября 2026 года.

Общие положения

T-Note («приложение») — офлайн-приложение для Android, разработанное независимым разработчиком («разработчик»). Разработчик не собирает, не хранит и не передаёт какие-либо данные пользователей на собственные серверы: у приложения нет серверной части, аналитики, рекламы и телеметрии.

Какие данные обрабатывает приложение

  • Заметки, списки и календарные события — хранятся локально в базе данных на устройстве пользователя.
  • Учётные данные для синхронизации (логин и пароль приложения календарного сервера либо OAuth-токен Google) — хранятся только на устройстве пользователя и используются исключительно для доступа к календарю, подключённому самим пользователем.

Синхронизация с календарными сервисами

Если пользователь подключил синхронизацию, приложение обменивается событиями с выбранным пользователем календарным сервисом:

  • Яндекс Календарь — по протоколу CalDAV (caldav.yandex.ru) с логином и паролем приложения, созданным пользователем в настройках Яндекса;
  • Google Календарь — по Google Calendar API с токеном, полученным через OAuth 2.0 по согласию пользователя.

Приложение использует доступ к Google Календарю (scope https://www.googleapis.com/auth/calendar.events) только для чтения, создания, изменения и удаления событий календаря, подключённого самим пользователем. Доступ к другим данным Google-аккаунта не запрашивается и не используется. Данные не используются для рекламы, не продаются и не передаются третьим лицам, кроме указанных выше календарных сервисов, выбранных самим пользователем.

Проверка обновлений

Раз в сутки приложение анонимно проверяет наличие новой версии: один GET-запрос к публичной странице приложения в каталоге RuStore (rustore.ru). Ни какие-либо данные пользователя, ни идентификаторы устройства при этом не передаются — запрос не содержит ничего, кроме адреса страницы приложения. Если обнаружена более новая версия, приложение показывает уведомление или диалог со ссылкой на RuStore; установку выполняет сам магазин. Без доступа к сети проверка просто не выполняется и ни на что не влияет, кроме содержимого упомянутого уведомления.

Удаление данных

Пользователь может в любой момент отключить синхронизацию в настройках приложения (токен и учётные данные удаляются с устройства), удалить события и заметки внутри приложения или удалить приложение целиком — все локальные данные при этом стираются с устройства.

Права Google-аккаунта

Отозвать доступ приложения к своему Google-аккаунту можно в настройках аккаунта: myaccount.google.com/permissions.

Контакты

T-Note Privacy Policy

Effective as of November 11, 2026.

General provisions

T-Note (the «app») is an offline Android application developed by an independent developer (the «developer»). The developer does not collect, store or transfer any user data to its own servers: the app has no backend, analytics, ads or telemetry.

What data the app processes

  • Notes, lists and calendar events — stored locally in a database on the user's device.
  • Sync credentials (login and app password of the calendar server, or a Google OAuth token) — stored only on the user's device and used exclusively to access the calendar connected by the user themselves.

Sync with calendar services

If the user has enabled sync, the app exchanges events with the calendar service chosen by the user:

  • Yandex Calendar — via the CalDAV protocol (caldav.yandex.ru) with a login and app password created by the user in the Yandex settings;
  • Google Calendar — via the Google Calendar API with a token obtained through OAuth 2.0 with the user's consent.

The app uses access to Google Calendar (scope https://www.googleapis.com/auth/calendar.events) only to read, create, modify and delete events in the calendar connected by the user themselves. No other Google account data is requested or used. The data is not used for advertising, is not sold and is not passed to third parties, except for the calendar services listed above that were chosen by the user themselves.

Update check

Once a day the app anonymously checks whether a new version exists: a single GET request to the app's public catalog page on RuStore (rustore.ru). No user data or device identifiers are transmitted — the request contains nothing but the address of the app's page. If a newer version is found, the app shows a notification or a dialog with a link to RuStore; the installation is performed by the store itself. Without network access the check simply does not happen and affects nothing except the content of the mentioned notification.

Data deletion

The user can disable sync in the app settings at any time (the token and credentials are deleted from the device), delete events and notes inside the app, or uninstall the app entirely — all local data is then erased from the device.

Google account rights

The app's access to your Google account can be revoked in the account settings: myaccount.google.com/permissions.

Contacts

Questions about privacy: taurlom@gmail.com. The app's source code is open: github.com/Taurlom/T-Note.

Política de privacidad de T-Note

Vigente desde el 11 de noviembre de 2026.

Disposiciones generales

T-Note (la «aplicación») es una aplicación de Android sin conexión desarrollada por un desarrollador independiente (el «desarrollador»). El desarrollador no recopila, almacena ni transfiere ningún dato de los usuarios a servidores propios: la aplicación no tiene backend, análisis, publicidad ni telemetría.

Qué datos procesa la aplicación

  • Notas, listas y eventos del calendario — se almacenan localmente en la base de datos del dispositivo del usuario.
  • Credenciales de sincronización (usuario y contraseña de aplicación del servidor de calendario o token OAuth de Google) — se almacenan solo en el dispositivo del usuario y se utilizan exclusivamente para acceder al calendario conectado por el propio usuario.

Sincronización con servicios de calendario

Si el usuario activó la sincronización, la aplicación intercambia eventos con el servicio de calendario elegido por el usuario:

  • Yandex Calendar — mediante el protocolo CalDAV (caldav.yandex.ru) con el usuario y la contraseña de aplicación creados por el usuario en los ajustes de Yandex;
  • Google Calendar — mediante la Google Calendar API con un token obtenido a través de OAuth 2.0 con el consentimiento del usuario.

La aplicación usa el acceso a Google Calendar (scope https://www.googleapis.com/auth/calendar.events) solo para leer, crear, modificar y eliminar eventos del calendario conectado por el propio usuario. No se solicita ni se usa acceso a otros datos de la cuenta de Google. Los datos no se usan para publicidad, no se venden ni se transfieren a terceros, salvo a los servicios de calendario mencionados arriba elegidos por el propio usuario.

Comprobación de actualizaciones

Una vez al día la aplicación comprueba de forma anónima si hay una versión nueva: una única petición GET a la página pública de la aplicación en el catálogo de RuStore (rustore.ru). No se transmiten datos del usuario ni identificadores del dispositivo: la petición no contiene nada más que la dirección de la página de la aplicación. Si se detecta una versión más nueva, la aplicación muestra una notificación o un diálogo con un enlace a RuStore; la instalación la realiza la propia tienda. Sin acceso a la red, la comprobación simplemente no se realiza y no afecta a nada, salvo al contenido de la notificación mencionada.

Eliminación de datos

El usuario puede desactivar la sincronización en los ajustes de la aplicación en cualquier momento (el token y las credenciales se eliminan del dispositivo), eliminar eventos y notas dentro de la aplicación o desinstalar la aplicación por completo: todos los datos locales se borran del dispositivo.

Derechos de la cuenta de Google

El acceso de la aplicación a la cuenta de Google puede revocarse en los ajustes de la cuenta: myaccount.google.com/permissions.

Contactos

Preguntas sobre privacidad: taurlom@gmail.com. El código fuente de la aplicación es abierto: github.com/Taurlom/T-Note.
