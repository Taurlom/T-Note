T-Note

Личные заметки и календарь для Android

T-Note — офлайн-приложение для заметок, списков и календаря. Данные хранятся на устройстве; по желанию пользователь подключает синхронизацию со своим календарём (Яндекс Календарь по CalDAV или Google Календарь по Calendar API) — с логином и паролем приложения либо со своим Google-аккаунтом.
